    狄利克雷双曲线法 & 杜教筛

    前置知识：Dirichlet 卷积、数论分块

    本文介绍 Dirichlet 双曲线法，它可用于在亚线性时间复杂度内计算两个数论函数的 Dirichlet 卷积的前缀和．通过对该算法的分析，可以引申出块筛的概念；据此，本文将进一步介绍块筛卷积的快速计算方法．最后，本文将介绍杜教筛，它可以用于计算两个数论函数在 Dirichlet 卷积意义下的商的前缀和．

    Dirichlet 双曲线法

    Dirichlet 双曲线法可以用于计算两个数论函数的 Dirichlet 卷积的前缀和．

    设 𝑓,𝑔,ℎf,g,h 是数论函数，且 ℎ =𝑓 ∗𝑔h=f∗g．那么，利用 Dirichlet 卷积的定义，ℎh 的前缀和

    𝐻(𝑛)=𝑛∑𝑘=1ℎ(𝑘)=𝑛∑𝑘=1∑𝑥𝑦=𝑘𝑓(𝑥)𝑔(𝑦).H(n)=∑k=1nh(k)=∑k=1n∑xy=kf(x)g(y).

    求和式遍历的点集恰为第一象限（不含坐标轴）中双曲线 𝑥𝑦 =𝑛xy=n 下方的整点集合．设整点 (𝑥,𝑦)(x,y) 的权值为 𝑓(𝑥)𝑔(𝑦)f(x)g(y)，那么 𝐻(𝑛)H(n) 就是这一权值的和．

    如图所示，这一权值和可以通过容斥原理计算：

    𝐻(𝑛)=⌊𝑥0⌋∑𝑥=1𝑓(𝑥)𝐺(⌊𝑛𝑥⌋)+⌊𝑦0⌋∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊𝑥0⌋)𝐺(⌊𝑦0⌋).H(n)=∑x=1⌊x0⌋f(x)G(⌊nx⌋)+∑y=1⌊y0⌋F(⌊ny⌋)g(y)−F(⌊x0⌋)G(⌊y0⌋).

    其中，𝐹,𝐺F,G 分别是 𝑓,𝑔f,g 的前缀和函数，(𝑥0,𝑦0)(x0,y0) 是双曲线 𝑥𝑦 =𝑛xy=n 上任意一个点．表达式中，第一项表示图中绿色区域的权值和，第二项表示图中橙色区域的权值和，第三项则表示两个区域重叠部分的权值和．这个表达式仅含有 ⌊𝑥0⌋ +⌊𝑦0⌋ +1⌊x0⌋+⌊y0⌋+1 项．对于合理选择的 (𝑥0,𝑦0)(x0,y0)，它的计算复杂度显著优于暴力计算 ℎ(𝑛)h(n) 的前缀和．这就是 Dirichlet 双曲线法（Dirichlet hyperbola method）．

    卷积前缀和点值的计算

    Dirichlet 双曲线法最基本的应用就是计算前缀和函数的点值 𝐻(𝑛)H(n)．

    如果 𝐹,𝐺F,G 的点值已知（或可以在 𝑂(1)O(1) 时间内计算），进而 𝑓,𝑔f,g 的点值也已知，那么 Dirichlet 双曲线法的表达式中每一项都可以在 𝑂(1)O(1) 时间内计算，总时间复杂度就等于 𝑂(𝑥0 +𝑦0)O(x0+y0)．因为 𝑥0𝑦0 =𝑛x0y0=n，所以由均值不等式可知，当 𝑥0 =𝑦0 =√𝑛x0=y0=n 时，就得到最低时间复杂度 𝑂(√𝑛)O(n)．

    这并非新的结果．在 Dirichlet 双曲线法的表达式中，令 𝑥0 >𝑛x0>n，就得到

    𝐻(𝑛)=𝑛∑𝑥=1𝑓(𝑥)𝐺(⌊𝑛𝑥⌋).H(n)=∑x=1nf(x)G(⌊nx⌋).

    利用 数论分块 的技巧，当 𝐹,𝐺F,G 的点值已知时，该式可以在 𝑂(√𝑛)O(n) 时间内计算．这实际上和本节得到的算法是几乎等价的：这两种方法需要的已知信息基本类似，计算的表达式也大致相同．

    等价性的说明

    细究数论分块的计算过程可以发现，实际计算的表达式为

    𝐻(𝑛)=∑𝑦∈𝐷(𝑛)(𝐹(⌊𝑛𝑦⌋)−𝐹(⌊𝑛𝑦+1⌋))𝐺(𝑦).H(n)=∑y∈D(n)(F(⌊ny⌋)−F(⌊ny+1⌋))G(y).

    其中，𝐷(𝑛) ={⌊𝑛𝑥⌋:1≤𝑥≤𝑛, 𝑥∈𝐍+}D(n)={⌊nx⌋:1≤x≤n, x∈N+} 是数论分块中的关键点集合．

    根据数论分块的性质可知，对于 𝑥 ≤√𝑛x≤n，对应分块的高度 𝑦 =⌊𝑛/𝑥⌋y=⌊n/x⌋ 各不相同，于是这些分块的长度都是 11，亦即

    ⌊𝑛𝑦+1⌋+1=𝑥=⌊𝑛𝑦⌋.⌊ny+1⌋+1=x=⌊ny⌋.

    因此，这些分块对应的求和为

    𝐼1=⌊√𝑛⌋∑𝑥=1(𝐹(𝑥)−𝐹(𝑥−1))𝐺(⌊𝑛𝑥⌋)=⌊√𝑛⌋∑𝑥=1𝑓(𝑥)𝐺(⌊𝑛𝑥⌋).I1=∑x=1⌊n⌋(F(x)−F(x−1))G(⌊nx⌋)=∑x=1⌊n⌋f(x)G(⌊nx⌋).

    剩下的分块，高度 𝑦y 遍历 1,2,⋯,𝑦∗ =⌊𝑛⌊√𝑛⌋+1⌋1,2,⋯,y∗=⌊n⌊n⌋+1⌋．对剩余的和式应用 Abel 变换（即分部积分法的求和形式），就得到

    𝐼2=𝑦∗∑𝑦=1(𝐹(⌊𝑛𝑦⌋)−𝐹(⌊𝑛𝑦+1⌋))𝐺(𝑦)=𝑦∗∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊𝑛𝑦∗+1⌋)𝐺(𝑦∗).I2=∑y=1y∗(F(⌊ny⌋)−F(⌊ny+1⌋))G(y)=∑y=1y∗F(⌊ny⌋)g(y)−F(⌊ny∗+1⌋)G(y∗).

    数论分块的性质说明，⌊𝑛/⌊√𝑛⌋⌋ ≥⌊√𝑛⌋⌊n/⌊n⌋⌋≥⌊n⌋．由此，分两种情形：

    • 当 ⌊𝑛/⌊√𝑛⌋⌋ =⌊√𝑛⌋⌊n/⌊n⌋⌋=⌊n⌋ 时，必然有 𝑦∗ <⌊√𝑛⌋y∗<⌊n⌋．由于它与 𝑥 =⌊√𝑛⌋x=⌊n⌋ 所在块相邻，块高只能恰好相差一，即 𝑦∗ =⌊√𝑛⌋ −1y∗=⌊n⌋−1．此时，有

      𝐼2=⌊√𝑛⌋−1∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊√𝑛⌋)𝐺(⌊√𝑛⌋−1)=⌊√𝑛⌋−1∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊√𝑛⌋)(𝐺(⌊√𝑛⌋)−𝑔(⌊√𝑛⌋))=⌊√𝑛⌋∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊√𝑛⌋)𝐺(⌊√𝑛⌋).I2=∑y=1⌊n⌋−1F(⌊ny⌋)g(y)−F(⌊n⌋)G(⌊n⌋−1)=∑y=1⌊n⌋−1F(⌊ny⌋)g(y)−F(⌊n⌋)(G(⌊n⌋)−g(⌊n⌋))=∑y=1⌊n⌋F(⌊ny⌋)g(y)−F(⌊n⌋)G(⌊n⌋).

    • 当 ⌊𝑛/⌊√𝑛⌋⌋ >⌊√𝑛⌋⌊n/⌊n⌋⌋>⌊n⌋ 时，必然有 𝑦∗ =⌊√𝑛⌋y∗=⌊n⌋．直接代入求和式，就得到

      𝐼2=⌊√𝑛⌋∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊√𝑛⌋)𝐺(⌊√𝑛⌋).I2=∑y=1⌊n⌋F(⌊ny⌋)g(y)−F(⌊n⌋)G(⌊n⌋).

    综上，除了一个 Abel 变换，数论分块的计算过程实际上就是在计算如下算式：

    𝐻(𝑛)=⌊√𝑛⌋∑𝑥=1𝑓(𝑥)𝐺(⌊𝑛𝑥⌋)+⌊√𝑛⌋∑𝑦=1𝐹(⌊𝑛𝑦⌋)𝑔(𝑦)−𝐹(⌊√𝑛⌋)𝐺(⌊√𝑛⌋).H(n)=∑x=1⌊n⌋f(x)G(⌊nx⌋)+∑y=1⌊n⌋F(⌊ny⌋)g(y)−F(⌊n⌋)G(⌊n⌋).

    这就是 (𝑥0,𝑦0) =(√𝑛,√𝑛)(x0,y0)=(n,n) 时 Dirichlet 双曲线法的表达式．因此可以说，两种算法的计算过程几乎等价．而且，由于 Dirichlet 双曲线法利用了更多数论分块的性质，避免了朴素数论分块中的不必要计算，常数更小一些．

    在处理实际问题时，已知 𝐹,𝐺F,G 点值这一条件可能过强．但是，Dirichlet 双曲线法（或对应的数论分块）其实并不需要 𝐹,𝐺F,G 的全部点值信息．观察求和表达式可知，其实只需要 𝐹F 和 𝐺G 在数论分块关键点集合

    𝐷(𝑛)={⌊𝑛𝑥⌋:1≤𝑥≤𝑛, 𝑥∈𝐍+}D(n)={⌊nx⌋:1≤x≤n, x∈N+}

    处的取值．它既是全体块高的集合，也是全体块的右端点集合．注意，根据数论分块的 性质 可知，这一集合包含所有 1 ≤𝑥 ≤√𝑛1≤x≤n 的整数值，因此，已知 𝐹,𝐺F,G 在 𝐷(𝑛)D(n) 处的取值就相当于已知 𝑓,𝑔f,g 在所有 1 ≤𝑥 ≤√𝑛1≤x≤n 处的取值．这一集合的大小是 Θ(√𝑛)Θ(n) 的，所以，计算 𝐻(𝑛)H(n) 时，只需要知道 𝐹,𝐺F,G 在一个稀疏集合处的点值信息．这个观察是优化数论函数前缀和计算的关键．

    块筛及其卷积

    有些时候，ℎ =𝑓 ∗𝑔h=f∗g 并非最终需要计算前缀和的函数，而只是中间步骤之一．根据前文分析，为了后续计算，需要求出前缀和函数 𝐻H 在集合 𝐷(𝑛)D(n) 处的取值．这就称为数论函数 ℎh 的 块筛：

    Sℎ(𝑛)={𝐻(𝑥):𝑥∈𝐷(𝑛)}.Sh(n)={H(x):x∈D(n)}.

    本节讨论 块筛卷积 问题的计算方法：已知 𝑓,𝑔f,g 的块筛时，求它们的 Dirichlet 卷积 ℎ =𝑓 ∗𝑔h=f∗g 的块筛．

    朴素算法

    朴素算法就是将块筛的计算看作是 |𝐷(𝑛)||D(n)| 次前缀和点值的计算．这样做的总时间复杂度为

    𝑂⎛⎜ ⎜⎝∑𝑑∈𝐷(𝑛)√𝑑⎞⎟ ⎟⎠=𝑂⎛⎜ ⎜⎝⌊√𝑛⌋∑𝑥=1√𝑥+⌊√𝑛⌋∑𝑥=1√𝑛𝑥⎞⎟ ⎟⎠=𝑂(∫√𝑛1√𝑥d𝑥+∫√𝑛1√𝑛𝑥d𝑥)=𝑂(𝑛3/4).O(∑d∈D(n)d)=O(∑x=1⌊n⌋x+∑x=1⌊n⌋nx)=O(∫1nxdx+∫1nnxdx)=O(n3/4).

    正是因为块筛是稀疏的，所以整个块筛可以在亚线性时间内求出．

    但是，这一算法显然过于暴力．集合 𝐷(𝑛)D(n) 中较小的那些元素取值相对稠密，所以块筛中相邻两个前缀和相差并不大，完全可以直接计算卷积 ℎh 的点值，再求它的前缀和．这比起对每个点都单独求一遍前缀和点值要更快．例如，对 𝑥 =1,2,⋯,⌊√𝑛⌋x=1,2,⋯,⌊n⌋ 分别计算前缀和点值需要

    𝑂⎛⎜ ⎜⎝⌊√𝑛⌋∑𝑥=1√𝑥⎞⎟ ⎟⎠=𝑂(𝑛3/4)O(∑x=1⌊n⌋x)=O(n3/4)

    的时间；但是，直接计算 ℎh 在这些点处的点值再累和，却只需要 𝑂(𝑛1/2log⁡𝑛)O(n1/2log⁡n) 的时间．尽管如此，如果只知道 𝑓,𝑔f,g 的块筛而不知道更多信息，那么这一思路是无法继续优化该算法复杂度的．这是因为块筛中只包含 𝑥 ≤√𝑛x≤n 处的点值信息，至多只能计算 ℎh 在 1 ≤𝑥 ≤√𝑛1≤x≤n 处的点值，而剩余前缀和点值的计算仍然需要 𝑂(𝑛3/4)O(n3/4) 的时间．

    利用点值信息优化

    如果已知信息除了 𝑓,𝑔f,g 的块筛外，还包含它们的更多点值，那么，确实可以改进这一算法的复杂度．实践中，这一算法通常应用于 𝑓,𝑔f,g 的点值可以快速预处理时．

    选择 𝑧 ≥√𝑛z≥n．卷积 ℎh 的块筛分为两部分：

    • 计算 𝑓 ∗𝑔f∗g 的卷积 ℎh 在 1 ≤𝑥 ≤𝑧1≤x≤z 处的点值，再直接累加求和得到 𝐻H 在 1 ≤𝑥 ≤𝑧1≤x≤z 处的点值．
    • 对于 𝑥 ∈𝐷(𝑛)x∈D(n) 且 𝑥 >𝑧x>z，通过 Dirichlet 双曲线法计算 𝐻H 在 𝑥x 处的点值．

    对于一般情形，这样做的时间复杂度为

    𝑂⎛⎜ ⎜⎝𝑧log⁡𝑧+∑𝑑∈𝐷(𝑛), 𝑑≥𝑧√𝑑⎞⎟ ⎟⎠=𝑂(𝑧log⁡𝑧+𝑛/𝑧∑𝑥=1√𝑛𝑥)=𝑂(𝑧log⁡𝑧+∫𝑛/𝑧1√𝑛𝑥d𝑥)=𝑂(𝑧log⁡𝑧+𝑛√𝑧).O(zlog⁡z+∑d∈D(n), d≥zd)=O(zlog⁡z+∑x=1n/znx)=O(zlog⁡z+∫1n/znxdx)=O(zlog⁡z+nz).

    当 𝑧 =(𝑛log⁡𝑛)2/3z=(nlog⁡n)2/3 时，总时间复杂度最小为 𝑂(𝑛2/3(log⁡𝑛)1/3)O(n2/3(log⁡n)1/3)．

    当然，Dirichlet 卷积 点值计算 的复杂度与 𝑓,𝑔,ℎf,g,h 的性质有关．对于 𝑓,𝑔,ℎf,g,h 有特殊性质的情形，最优分点和复杂度均略有不同：

    • 如果 𝑓f 或 𝑔g 是积性的，那么当 𝑧 =(𝑛log⁡log⁡𝑛)2/3z=(nlog⁡log⁡n)2/3 时，总时间复杂度最小为 𝑂(𝑛2/3(log⁡log⁡𝑛)1/3)O(n2/3(log⁡log⁡n)1/3)．
    • 如果 ℎh 是积性的，那么当 𝑧 =𝑛2/3z=n2/3 时，总时间复杂度最小为 𝑂(𝑛2/3)O(n2/3)．

    应用这一优化并不需要 𝑓,𝑔f,g 的全部点值，而只需要它们在 1 ≤𝑥 ≤𝑧1≤x≤z 处的点值．因为这一算法也得到了 ℎh 在 1 ≤𝑥 ≤𝑧1≤x≤z 处的点值，所以当 ℎh 作为中间变量时，同样可以利用 ℎh 的点值优化后续计算过程．数论函数的块筛，再加上它这些点值，就构成了一个增强版的块筛：它们是在 𝑂(𝑛2/3+𝜀)O(n2/3+ε) 时间内计算卷积前缀和的全部必要信息．

    快速块筛卷积

    前置知识：快速傅里叶变换

    注意

    初学者可以跳过本节内容．

    本节讨论周康阳在 2024 年集训队论文提出的快速块筛卷积算法．它可以在 𝑂(√𝑛log2⁡𝑛)O(nlog2⁡n) 时间内根据块筛 S𝑓Sf 和 S𝑔Sg 计算出它们卷积 SℎSh 的取值．这一算法不依赖于额外的点值信息和数论函数的积性，但实现较为复杂．

    块筛卷积问题希望计算

    ℎ(𝑧)=∑𝑥𝑦=𝑧𝑓(𝑥)𝑔(𝑦)h(z)=∑xy=zf(x)g(y)

    在块筛 𝐷(𝑛) ={⌊𝑛/𝑡⌋ :1 ≤𝑡 ≤𝑛}D(n)={⌊n/t⌋:1≤t≤n} 处的前缀和．对于这一问题，单一贡献可以由 (𝑥,𝑦,𝑡)(x,y,t) 标记，即将项 𝑓(𝑥)𝑔(𝑦)f(x)g(y) 累加到 ⌊𝑛/𝑡⌋⌊n/t⌋ 处前缀和的过程．算法将这些贡献分成若干组处理．

    首先，考虑 𝑥 >√𝑛x>n 的所有点对于这一系列前缀和的贡献，那些 𝑦 >√𝑛y>n 的贡献类似．因为所有贡献必须满足 𝑥𝑦 ≤⌊𝑛/𝑡⌋xy≤⌊n/t⌋，即 𝑥𝑦𝑡 ≤𝑛xyt≤n，所以只需要枚举所有可能的 𝑡,𝑦t,y，利用前缀和技巧以及块筛 S𝑓Sf 中的信息，就可以在 𝑂(∑𝑡,𝑦:𝑡𝑦≤√𝑛1) =𝑂(√𝑛log⁡𝑛)O(∑t,y:ty≤n1)=O(nlog⁡n) 时间内计算出这部分贡献．

    然后，考虑 ⌊𝑛/𝑡⌋ ≤√𝑛⌊n/t⌋≤n 的这部分贡献．这一部分同样可以暴力枚举所有可能的 𝑥,𝑦x,y 完成，时间复杂度仍然是 𝑂(∑𝑥,𝑦:𝑥𝑦≤√𝑛1) =𝑂(√𝑛log⁡𝑛)O(∑x,y:xy≤n1)=O(nlog⁡n)．这一部分实际上得到了函数 ℎh 在 𝐷(𝑛)D(n) 的前 ⌊√𝑛⌋⌊n⌋ 个点值．

    考虑剩下的贡献，即满足 𝑥,𝑦 ≤√𝑛x,y≤n 且 ⌊𝑛/𝑡⌋ >√𝑛⌊n/t⌋>n 的贡献．所有贡献必须满足 𝑥𝑦𝑡 ≤𝑛xyt≤n，亦即 ln⁡𝑥 +ln⁡𝑦 ≤ln⁡(𝑛/𝑡)ln⁡x+ln⁡y≤ln⁡(n/t)．取正数 𝑆S，可以利用 ⌈𝑆ln⁡𝑥⌉ +⌈𝑆ln⁡𝑦⌉ ≤𝑆ln⁡(𝑛/𝑡)⌈Sln⁡x⌉+⌈Sln⁡y⌉≤Sln⁡(n/t) 近似估计这一条件．定义多项式 𝜎𝑓(𝑢)σf(u) 和 𝜎𝑔(𝑢)σg(u)，使得它们的系数 [𝑢𝑘]𝜎𝑓[uk]σf 和 [𝑢𝑘]𝜎𝑔[uk]σg 分别等于满足 ⌈𝑆ln⁡𝑥⌉ =𝑘⌈Sln⁡x⌉=k 时 𝑓(𝑥)f(x) 的和以及满足 ⌈𝑆ln⁡𝑦⌉ =𝑘⌈Sln⁡y⌉=k 时 𝑔(𝑦)g(y) 的和（只考虑 𝑥,𝑦 ≤√𝑛x,y≤n 的这一部分）．利用快速傅里叶变换（FFT）可以得到它们的乘积 𝜎𝑓𝜎𝑔σfσg，它的系数 [𝑢𝑘](𝜎𝑓𝜎𝑔)[uk](σfσg) 就表示 ⌈𝑆ln⁡𝑥⌉ +⌈𝑆ln⁡𝑦⌉ =𝑘⌈Sln⁡x⌉+⌈Sln⁡y⌉=k 时 𝑓(𝑥)𝑔(𝑦)f(x)g(y) 的和．由此，只需要对于每个 𝐷(𝑛)D(n) 中剩下的每个 ⌊𝑛/𝑡⌋⌊n/t⌋ 都找到满足 𝑘 ≤𝑆ln⁡(𝑛/𝑡)k≤Sln⁡(n/t) 的最大 𝑘k 值，就可以得到这一部分贡献的估计值．

    最后，对于这一部分贡献进行误差修正．前文试图利用更强的条件 ⌈𝑆ln⁡𝑥⌉ +⌈𝑆ln⁡𝑦⌉ ≤𝑆ln⁡(𝑛/𝑡)⌈Sln⁡x⌉+⌈Sln⁡y⌉≤Sln⁡(n/t) 去近似 ln⁡𝑥 +ln⁡𝑦 ≤ln⁡(𝑛/𝑡)ln⁡x+ln⁡y≤ln⁡(n/t)，可能会遗漏部分贡献．这只会发生在 ⌈𝑆ln⁡𝑥⌉ +⌈𝑆ln⁡𝑦⌉ >𝑆ln⁡(𝑛/𝑡)⌈Sln⁡x⌉+⌈Sln⁡y⌉>Sln⁡(n/t) 时，所以有

    𝑆ln⁡𝑥+1+𝑆ln⁡𝑦+1≥⌈𝑆ln⁡𝑥⌉+⌈𝑆ln⁡𝑦⌉>𝑆ln⁡(𝑛/𝑡)≥𝑆ln⁡𝑥+𝑆ln⁡𝑦.Sln⁡x+1+Sln⁡y+1≥⌈Sln⁡x⌉+⌈Sln⁡y⌉>Sln⁡(n/t)≥Sln⁡x+Sln⁡y.

    这相当于

    𝑥𝑦𝑡∈(𝑛e−2/𝑆,𝑛].xyt∈(ne−2/S,n].

    这是一个长度为 𝑂(𝑛/𝑆)O(n/S) 的区间．枚举区间内所有可能的贡献 (𝑥,𝑦,𝑡)(x,y,t)，逐个检验是否遗漏，就可以完成误差的修正．为了快速枚举区间内所有贡献，可以首先筛出不超过 √𝑛n 的全部素数，再利用这些素数去除区间中的整数，剩下的因子必然是大于 √𝑛n 的素数，由此就可以得到区间内所有整数的素因数分解，进而可以快速枚举所有可能的 (𝑥,𝑦,𝑡)(x,y,t)．

  long long n, b;
  std::vector<int> s1, s2;

  BlockSieve(long long _n)
      : n(_n), b(std::sqrt(_n + 0.25l)), s1(b + 1), s2(b + 1) {}

// Fast block sieve convolution by ZKY.
BlockSieve block_sieve_convolute(const BlockSieve& f, const BlockSieve& g) {
  // Special cases for n <= 3 are not implemented.
  // The upper bound is a loose bound for NTT to work for M = 998244353.
  assert(f.n == g.n && f.n > 3 && f.n < 1e11);
  long long n = f.n, b = f.b;
  BlockSieve h(n);
  std::vector<int> df(b + 1), dg(b + 1);
  for (int i = 1; i <= b; ++i) {
    df[i] = (f.s1[i] + M - f.s1[i - 1]) % M;
    dg[i] = (g.s1[i] + M - g.s1[i - 1]) % M;
  }
  // Prefix sum trick for x or y > sqrt(n).
  for (int t = 1; t <= n / (b + 1); ++t) {
    long long x;
    for (int y = 1; (x = n / (t * y)) > b; ++y) {
      (h.s2[t] += (long long)dg[y] * (f.s2[n / x] + M - f.s1[b]) % M) %= M;
      (h.s2[t] += (long long)df[y] * (g.s2[n / x] + M - g.s1[b]) % M) %= M;
    }
  }
  // Brutal force for small x*y.
  for (int x = 1; x <= b; ++x) {
    for (int y = 1; x * y <= b; ++y) {
      (h.s1[x * y] += (long long)df[x] * dg[y] % M) %= M;
    }
  }
  for (int i = 1; i <= b; ++i) {
    (h.s1[i] += h.s1[i - 1]) %= M;
  }
  // Approximation.
  std::vector<int> id1(b + 1);
  for (int i = 1; i <= b; ++i) {
    id1[i] = std::ceil(b * std::log(i));
  }
  std::vector<long double> id2(b + 1);
  for (int i = 1; i <= b; ++i) {
    id2[i] = b * std::log(1.0l * n / i);
  }
  std::vector<int> sf(id1[b] + 1), sg(id1[b] + 1);
  for (int i = 1; i <= b; ++i) {
    (sf[id1[i]] += df[i]) %= M;
    (sg[id1[i]] += dg[i]) %= M;
  }
  auto sh = ntt_mul(sf, sg);
  for (int i = 1; i < (int)sh.size(); ++i) {
    (sh[i] += sh[i - 1]) %= M;
  }
  for (int t = 1; t <= n / (b + 1); ++t) {
    int k = std::min((int)std::floor(id2[t]), (int)sh.size() - 1);
    (h.s2[t] += sh[k]) %= M;
  }
  // Correction.
  auto primes = get_primes(b);  // Obtain primes not exceeding b.
  long long l = n * std::exp(-2.0l / b);
  std::vector<long long> co(n - l + 1);
  std::iota(co.begin(), co.end(), l);
  std::vector<std::vector<std::pair<long long, int>>> fac(n - l + 1);
  for (int p : primes) {
    for (int i = (l + p - 1) / p * p - l; i <= n - l; i += p) {
      int e = 0;
      for (; co[i] % p == 0; co[i] /= p) ++e;
      fac[i].emplace_back(p, e);
    }
  }
  for (int i = 0; i <= n - l; ++i) {
    if (co[i] != 1) {
      fac[i].emplace_back(co[i], 1);
    }
  }
  long long num = 0;
  std::vector<std::pair<long long, int>> cur;
  auto dfs = [&](auto&& dfs, int k, int x, int y) {
    if (k == (int)cur.size()) {
      auto t = num / x / y;
      if (t && t <= n / (b + 1) && id1[x] + id1[y] > id2[t]) {
        (h.s2[t] += (long long)df[x] * dg[y] % M) %= M;
      }
      return;
    }
    auto p = cur[k].first;
    auto e = cur[k].second;
    long long nx = x;
    for (int e1 = 0; e1 <= e; ++e1) {
      if (e1) {
        nx *= p;
        if (nx > b) break;
      }
      long long ny = y;
      for (int e2 = 0; e1 + e2 <= e; ++e2) {
        if (e2) {
          ny *= p;
          if (ny > b) break;
        }
        dfs(dfs, k + 1, nx, ny);
      }
    }
  };
  for (int i = 0; i <= n - l; ++i) {
    num = l + i;
    cur = fac[i];
    dfs(dfs, 0, 1, 1);
  }
  return h;
}

constexpr int M = 998244353;

// Compute the Dirichlet convolution h = f * g.
// Assume that h is multiplicative.
auto dirichlet_convolute(const std::vector<int>& f, const std::vector<int>& g) {
  int n = f.size() - 1;
  std::vector<int> h(n + 1), primes, rem(n + 1), lpf(n + 1);
  std::vector<bool> vis(n + 1);
  h[1] = 1;
  for (int x = 2; x <= n; ++x) {
    if (!vis[x]) {
      primes.push_back(x);
      rem[x] = 1;
      lpf[x] = x;
    }
    for (int p : primes) {
      if (x * p > n) break;
      vis[x * p] = true;
      rem[x * p] = x % p ? x : rem[x];
      lpf[x * p] = p;
      if (x % p == 0) break;
    }
    if (rem[x] == 1) {  // prime powers.
      for (int k = x; k; k /= lpf[x]) {
        (h[x] += (long long)f[k] * g[x / k] % M) %= M;
      }
    } else {  // other cases.
      h[x] = (long long)h[rem[x]] * h[x / rem[x]] % M;
    }
  }
  return h;
}

// Block sieve convolution for multiplicative functions.
struct BlockSieve {
  int n, z;
  std::vector<int> f, F, F2;

  BlockSieve(int _n, int _z)
      : n(_n), z(_z), f(_z + 1), F(_z + 1), F2(_n / _z + 1) {}

  int sum(int x) const { return x <= z ? F[x] : F2[n / x]; }

  BlockSieve operator*(const BlockSieve& oth) const {
    assert(n == oth.n && z == oth.z);
    BlockSieve res(n, z);
    res.f = dirichlet_convolute(f, oth.f);
    for (int i = 1; i <= z; ++i) {
      res.F[i] = (res.F[i - 1] + res.f[i]) % M;
    }
    for (int i = 1; i <= n / z; ++i) {
      int k = n / i;
      int sqr = std::sqrt(k + 0.25l);
      for (int x = 1; x <= sqr; ++x) {
        (res.F2[i] += (long long)f[x] * oth.sum(k / x) % M) %= M;
        (res.F2[i] += (long long)sum(k / x) * oth.f[x] % M) %= M;
      }
      (res.F2[i] += (M - (long long)sum(sqr) * oth.sum(sqr) % M)) %= M;
    }
    return res;
  }
};

int main() {
  int n, k;
  std::cin >> k >> n;
  int z = std::pow(n, 2.0l / 3);
  // Initialization of inputs.
  BlockSieve po(n, z);
  for (int i = 1; i <= z; ++i) {
    po.f[i] = 1;
    po.F[i] = i;
  }
  for (int i = 1; i <= n / z; ++i) {
    po.F2[i] = n / i;
  }
  BlockSieve res(n, z);
  res.f[1] = 1;
  for (int i = 1; i <= z; ++i) {
    res.F[i] = 1;
  }
  for (int i = 1; i <= n / z; ++i) {
    res.F2[i] = 1;
  }
  // Binary exponentiation.
  for (; k; k >>= 1) {
    if (k & 1) res = res * po;
    po = po * po;
  }
  std::cout << res.sum(n) << std::endl;
  return 0;

    设 𝜇μ 和 𝜑φ 分别是莫比乌斯函数和欧拉函数．求 𝑆1(𝑛) =∑𝑛𝑖=1𝜇(𝑖)S1(n)=∑i=1nμ(i) 和 𝑆2(𝑛) =∑𝑛𝑖=1𝜑(𝑖)S2(n)=∑i=1nφ(i) 的值．数据范围：1 ≤𝑛 <2311≤n<231.

    解答

    注意到 Dirichlet 卷积关系式：

    𝜀=𝜇∗1, id=𝜑∗1.ε=μ∗1, id=φ∗1.

    其中，𝜀(𝑛) =[𝑛 =1]ε(n)=[n=1] 是 Dirichlet 卷积的单位元函数，id⁡(𝑛) =𝑛id⁡(n)=n 是恒等函数，1(𝑛) =11(n)=1 是常值函数．因为这三个函数的前缀和都可以在 𝑂(1)O(1) 时间内计算且都是积性函数，所以，利用前文介绍的杜教筛方法就可以在 𝑂(𝑛2/3)O(n2/3) 时间内计算．

    对于欧拉函数的前缀和的计算，另一种方法是利用 莫比乌斯反演．注意到

    𝑆2(𝑛)=𝑛∑𝑖=1𝜑(𝑖)=𝑛∑𝑖=1𝑖∑𝑗=1[𝑖⟂𝑗]=𝑛∑𝑖=1𝑖∑𝑗=1∑𝑑𝜇(𝑑)[𝑑∣𝑖][𝑑∣𝑗]=∑𝑑𝜇(𝑑)12⌊𝑛𝑑⌋(⌊𝑛𝑑⌋+1).S2(n)=∑i=1nφ(i)=∑i=1n∑j=1i[i⟂j]=∑i=1n∑j=1i∑dμ(d)[d∣i][d∣j]=∑dμ(d)12⌊nd⌋(⌊nd⌋+1).

    在数论分块的过程中，需要 𝜇(𝑑)μ(d) 的前缀和，而这可以通过杜教筛预处理出来．时间复杂度仍然是 𝑂(𝑛2/3)O(n2/3)．

    #include <cstring>
#include <iostream>
#include <map>
using namespace std;
constexpr int MAXN = 2000010;
long long T, n, pri[MAXN], cur, mu[MAXN], sum_mu[MAXN];
bool vis[MAXN];
map<long long, long long> mp_mu;

long long S_mu(long long x) {  // 求mu的前缀和
  if (x < MAXN) return sum_mu[x];
  if (mp_mu[x]) return mp_mu[x];  // 如果map中已有该大小的mu值，则可直接返回
  long long ret = (long long)1;
  for (long long i = 2, j; i <= x; i = j + 1) {
    j = x / (x / i);
    ret -= S_mu(x / i) * (j - i + 1);
  }
  return mp_mu[x] = ret;  // 路径压缩，方便下次计算
}

long long S_phi(long long x) {  // 求phi的前缀和
  long long ret = (long long)0;
  long long j;
  for (long long i = 1; i <= x; i = j + 1) {
    j = x / (x / i);
    ret += (S_mu(j) - S_mu(i - 1)) * (x / i) * (x / i);
  }
  return (ret - 1) / 2 + 1;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> T;
  mu[1] = 1;
  for (int i = 2; i < MAXN; i++) {  // 线性筛预处理mu数组
    if (!vis[i]) {
      pri[++cur] = i;
      mu[i] = -1;
    }
    for (int j = 1; j <= cur && i * pri[j] < MAXN; j++) {
      vis[i * pri[j]] = true;
      if (i % pri[j])
        mu[i * pri[j]] = -mu[i];
      else {
        mu[i * pri[j]] = 0;
        break;
      }
    }
  }
  for (int i = 1; i < MAXN; i++)
    sum_mu[i] = sum_mu[i - 1] + mu[i];  // 求mu数组前缀和
  while (T--) {
    cin >> n;
    cout << S_phi(n) << ' ' << S_mu(n) << '\n';
  }
  return 0;
}
    「LuoguP3768」简单的数学题

    给定 𝑝,𝑛p,n，计算

    𝑛∑𝑖=1𝑛∑𝑗=1𝑖𝑗⋅gcd(𝑖,𝑗)(mod𝑝).∑i=1n∑j=1nij⋅gcd(i,j)(modp).

    数据范围：𝑛 ≤1010n≤1010，5 ×108 ≤𝑝 ≤1.1 ×1095×108≤p≤1.1×109 且 𝑝p 是质数．

    解答

    利用 欧拉函数 的性质，做如下反演：

    𝑇(𝑛)=𝑛∑𝑖=1𝑛∑𝑗=1𝑖𝑗⋅gcd(𝑖,𝑗)=𝑛∑𝑖=1𝑛∑𝑗=1𝑖𝑗∑𝑑𝜑(𝑑)[𝑑∣𝑖][𝑑∣𝑗]=∑𝑑𝜑(𝑑)(⌊𝑛/𝑑⌋∑𝑖=1𝑖𝑑)(⌊𝑛/𝑑⌋∑𝑗=1𝑗𝑑)=∑𝑑𝑑2𝜑(𝑑)𝐹(⌊𝑛𝑑⌋)2.T(n)=∑i=1n∑j=1nij⋅gcd(i,j)=∑i=1n∑j=1nij∑dφ(d)[d∣i][d∣j]=∑dφ(d)(∑i=1⌊n/d⌋id)(∑j=1⌊n/d⌋jd)=∑dd2φ(d)F(⌊nd⌋)2.

    其中，𝐹(𝑛) =12𝑛(𝑛 +1)F(n)=12n(n+1)．该式可以通过数论分块计算，但需要预处理出 𝑑2𝜑(𝑑)d2φ(d) 的前缀和．

    为此，可以利用杜教筛．记 𝑓(𝑛) =(id2⁡𝜑)(𝑛)f(n)=(id2⁡φ)(n) 和 𝑆(𝑛) =∑𝑛𝑖=1𝑓(𝑖)S(n)=∑i=1nf(i)．应用杜教筛的关键是构造出函数 𝑔g，使得 𝑓 ∗𝑔f∗g 和 𝑔g 都可以快速求和．前文已经讨论了用杜教筛预处理 𝜑φ 前缀和的方法，这只需要利用关系：id =𝜑 ∗1id=φ∗1．相较于 𝜑φ，这里的 𝑓f 多了一个 id2id2．由于 idid 是完全积性函数，利用 Dirichlet 卷积的 性质，只需要类似地将每一项都乘以 id2id2，就得到

    id3=𝑓∗id2⁡.id3=f∗id2⁡.

    因为 id2⁡(𝑛) =𝑛2id2⁡(n)=n2 和 id3⁡(𝑛) =𝑛3id3⁡(n)=n3 的前缀和都可以在 𝑂(1)O(1) 时间内计算，𝑓f 的前缀和就可以在 𝑂(𝑛2/3)O(n2/3) 时间内预处理得到．再加上数论分块，整体时间复杂度仍然是 𝑂(𝑛2/3)O(n2/3)．

    // 不要为了省什么内存把数组开小,会卡80
#include <cmath>
#include <iostream>
#include <map>
using namespace std;
constexpr int N = 5e6, NP = 5e6, SZ = N;
long long n, P, inv2, inv6, s[N];
int phi[N], p[NP], cnt, pn;
bool bp[N];
map<long long, long long> s_map;

long long ksm(long long a, long long m) {  // 求逆元用
  long long res = 1;
  while (m) {
    if (m & 1) res = res * a % P;
    a = a * a % P, m >>= 1;
  }
  return res;
}

void prime_work(int k) {  // 线性筛phi，s
  bp[0] = bp[1] = true, phi[1] = 1;
  for (int i = 2; i <= k; i++) {
    if (!bp[i]) p[++cnt] = i, phi[i] = i - 1;
    for (int j = 1; j <= cnt && i * p[j] <= k; j++) {
      bp[i * p[j]] = true;
      if (i % p[j] == 0) {
        phi[i * p[j]] = phi[i] * p[j];
        break;
      } else
        phi[i * p[j]] = phi[i] * phi[p[j]];
    }
  }
  for (int i = 1; i <= k; i++)
    s[i] = (1ll * i * i % P * phi[i] % P + s[i - 1]) % P;
}

long long s3(long long k) {  // 立方和
  return k %= P, (k * (k + 1) / 2) % P * ((k * (k + 1) / 2) % P) % P;
}

long long s2(long long k) {  // 平方和
  return k %= P, k * (k + 1) % P * (k * 2 + 1) % P * inv6 % P;
}

long long calc(long long k) {  // 计算S(k)
  if (k <= pn) return s[k];
  if (s_map[k]) return s_map[k];  // 对于超过pn的用map离散存储
  long long res = s3(k), pre = 1, cur;
  for (long long i = 2, j; i <= k; i = j + 1)
    j = k / (k / i), cur = s2(j),
    res = (res - calc(k / i) * (cur - pre) % P) % P, pre = cur;
  return s_map[k] = (res + P) % P;
}

long long solve() {
  long long res = 0, pre = 0, cur;
  for (long long i = 1, j; i <= n; i = j + 1) {
    j = n / (n / i);
    cur = calc(j);
    res = (res + (s3(n / i) * (cur - pre)) % P) % P;
    pre = cur;
  }
  return (res + P) % P;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  cin >> P >> n;
  inv2 = ksm(2, P - 2), inv6 = ksm(6, P - 2);
  pn = (long long)pow(n, 0.666667);  // n^(2/3)
  prime_work(pn);
  cout << solve();
  return 0;
}
